# Dashboard Module

**Route:** `/dashboard`
**Frontend:** `corporate-react-1/src/modules/Dashboard/`

## Overview

The Dashboard provides corporate users with a high-level overview of their hiring activity — drive statistics, institute partnerships, and key metrics cards. It serves as the landing page after authentication.

---

## UI Components

| Component | Path | Purpose |
|-----------|------|---------|
| `Container/index.js` | Main container | Dashboard layout and data orchestration |
| `Partials/DashboardCards/` | Metric cards | Summary cards with key hiring numbers |
| `Partials/DashboardStats/` | Statistics | Detailed statistics display |
| `Partials/InstitutesDetails/` | Institutes | Institute partnership details |

---

## Key Features

- **Metric cards:** Quick overview of role counts, candidate counts, active drives
- **Institute details:** View associated institutes and their engagement
- **Statistics:** Aggregate hiring data visualizations
