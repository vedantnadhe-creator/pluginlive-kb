# Settings Module

**Route:** `/settings`
**Frontend:** `admin-react/src/modules/Settings/`

## Overview

The Settings module provides general admin portal settings. It is separate from SystemConfig (which handles platform-wide configuration) and focuses on admin-specific preferences and configuration.
